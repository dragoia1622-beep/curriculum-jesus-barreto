# Currículum web de Jesús Barreto

Portafolio de desarrollo web de Barrett Tecnología y perfil profesional de Chef Guayoyo. Incluye proyectos, formación, certificados y currículums descargables en español e inglés.

## Abrir en el ordenador

Abre `index.html` en el navegador. El sitio usa HTML, CSS y JavaScript y se puede publicar sin un paso de compilación.

## Subir a GitHub

1. Descomprime el ZIP y abre la carpeta `curriculum-jesus-barreto`.
2. Crea un repositorio en GitHub. Sube el contenido de la carpeta para que `index.html` quede en la raíz del repositorio junto con `assets/` y `en/`.
3. Si usas GitHub Desktop, puedes crear el repositorio local con esta carpeta, hacer el primer commit y pulsar **Publish repository**.

## Mostrar el currículum como página web

1. En el repositorio, entra en **Settings → Pages**.
2. En **Source**, selecciona **Deploy from a branch**.
3. Elige **main** y **/(root)** y pulsa **Save**.
4. Cuando termine el despliegue, abre **Visit site** en esa misma pantalla.

[Documentación de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Archivos principales

- `index.html` es la portada en español.
- `en/index.html` es la portada en inglés.
- `barrett.css` y `app.js` contienen los estilos y el comportamiento.
- `assets/` contiene las imágenes, los certificados y los PDF.
